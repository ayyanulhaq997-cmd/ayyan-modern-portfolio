# Ayyan Modern Portfolio

## Run locally
1. Install Node.js LTS from https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown in the terminal (usually http://localhost:5173).

## Before publishing
- In `src/main.jsx`, replace `YOUR_EMAIL@example.com` with your real email address.
- Update the contact section's placeholder email text.
- Confirm every project link and description is accurate.
- Only add testimonials or client results that are real and have permission to be shared.

## Production build
```bash
npm run build
npm run preview
```

You can deploy this Vite app to Vercel, Netlify, or another static hosting provider.
